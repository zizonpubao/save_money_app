# SaveLog PRD (제품 요구사항)

## 한 줄 정의
"오늘 참은 소비"를 항목·금액으로 기록하고, 날짜별/월별로 얼마를 아꼈는지 보여주는 개인용 iOS 앱.

## 사용자
개발자 본인 1명. 앱스토어 출시 없음. Expo Go로 실행.

## 핵심 개념
- **기록(Entry)**: 하루에 여러 개 가능. `항목명`, `금액`, `날짜`, `카테고리(선택)`, `메모(선택)`
- **카테고리**: 기본 제공 + 사용자 추가. 기본값: 커피, 밥값, 배달, 택시, 쇼핑, 술, 간식, 구독, 기타
- **절약액**: 기록된 금액의 합. 실제 지출을 추적하지 않는다 (가계부가 아님).

## 데이터 모델 (SQLite)
```sql
CREATE TABLE entries (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  date TEXT NOT NULL,            -- 'YYYY-MM-DD' (로컬 날짜)
  title TEXT NOT NULL,           -- 항목명
  amount INTEGER NOT NULL,       -- 원 단위 정수, 0 초과
  category_id INTEGER,           -- NULL 허용
  memo TEXT,
  created_at TEXT NOT NULL,      -- ISO8601
  updated_at TEXT NOT NULL,
  FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE SET NULL
);
CREATE INDEX idx_entries_date ON entries(date);

CREATE TABLE categories (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE,
  emoji TEXT NOT NULL,
  sort_order INTEGER NOT NULL DEFAULT 0,
  is_default INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE schema_version (version INTEGER NOT NULL);

-- v3 (M3.5)
CREATE TABLE settings (key TEXT PRIMARY KEY, value TEXT NOT NULL);
-- monthly_goal: 원 정수 문자열 / goal_reached_month: 'YYYY-MM' (달성 축하 월 1회 보장)
```

## 화면
하단 탭 3개: **홈**(이번 달 카드 + 입력 + 최근 기록) · **기록**(월/년 단위 통계와 전체 목록) · **설정**. 2026-09-24 사용자 결정으로 "기록/월별" 에서 재구성.


### 1. 홈 탭 (`app/(tabs)/index.tsx`) — 하단 탭 이름 "홈"
- 상단: **이번 달 절약액** 크게 표시, 오늘 절약액과 오늘 날짜는 작게
- 중앙: 최근 기록 목록. **날짜별 그룹**(섹션 헤더 = 날짜 + 그날 합계), 최신순
- 목록 범위: 기본은 **이번 달**, 맨 아래 "이전 달 더 보기"로 한 달씩 추가 로드. (월/년 토글은 기록 탭으로 이동, 홈에는 없음)
- 각 행: 카테고리 이모지 · 항목명 · 금액. 탭하면 수정 화면, 왼쪽 스와이프로 삭제(확인 알림)
- 하단 우측: `+` 플로팅 버튼 → 입력 시트

### 2. 입력 시트 (바텀시트 or 모달)
- 필드 순서: **금액**(숫자 키패드, 자동 콤마) → 항목명 → 카테고리(가로 스크롤 칩) → 날짜(기본 오늘, 탭하면 변경) → 메모
- 카테고리 칩을 고르면 항목명이 비어있을 때 카테고리명으로 자동 채움
- **빠른 입력**: 최근 사용한 항목 3~5개를 칩으로 노출, 탭하면 항목명+카테고리+마지막 금액 자동 채움
- 저장 시 **축하 이펙트** (M2부터): 햅틱(`expo-haptics` success) + 이번 달 절약액이 이전 값에서 새 값으로 **카운트업** + 절약액 카드 **펄스/스케일 애니메이션** + 시트 닫힘. 짧고(1초 내) 타격감 있게, 사용자가 "아꼈다"는 느낌을 받도록. `reanimated`로 구현, 외부 라이브러리 없음
- 금액 0 또는 빈 항목명이면 저장 버튼 비활성

### 3. 기록 탭 (`app/(tabs)/monthly.tsx`) — 하단 탭 이름 "기록", 상단에 **월 / 년** 단위 토글
- 상단: 월 모드 `< 2026년 9월 >`, 년 모드 `< 2026년 >` 이동. 가장 오래된 기록까지, 미래 불가
- **년 모드**: 년 총 절약액·건수·월 평균, **월별 막대 12개**(높이 = 그달 합계), 카테고리별 년 합계, 하단 목록은 **월별 섹션**(헤더 = 월 + 그달 합계). 막대 탭 → "9월 · 184,000원" 툴팁
- **월↔년 전환 규칙**: 월→년은 보던 달의 해로, 년→월은 보던 달이 그 해면 그대로·아니면 올해는 이번 달/지난 해는 12월. 월 평균 = 이번 해면 이번 달까지 경과 개월 수, 지난 해면 12로 나눔. 년 막대 축 라벨은 숫자만 1~12 전부 (일별 축과 같은 모양, 12칸이라 폭 충분). 전환 시 툴팁 닫힘 + 맨 위로 스크롤
- **월 총 절약액**, 기록 건수, 하루 평균
- **일별 막대 그래프**: 1일~말일, 높이 = 그날 합계 (View로 직접 그림). 축 라벨은 1·5·10·15·20·25·30·말일 (5일 단위)
- **카테고리별 합계**: 많은 순, 비율 바 + 금액
- 하단: 해당 월 기록 전체 목록 (날짜 그룹)
- 월 이동 범위: 이전은 가장 오래된 기록이 있는 달까지, 다음은 이번 달까지(미래 불가). 끝에 닿으면 화살표 비활성
- **하루 평균 기준**: 이번 달이면 오늘까지 경과일로, 지난 달이면 그 달 전체 일수로 나눈다. 기록 0건이면 0
- **막대 탭 = 툴팁**: 막대를 탭하면 그날 금액 툴팁("23일 · 12,000원")만 뜨고, 같은 막대나 차트 다른 곳을 탭하거나 월을 옮기면 닫힌다. 기록 없는 날은 빈 트랙
- 카테고리 없음(NULL)·지워진 카테고리는 "미분류 📦" 한 줄로 묶어 맨 뒤에 둔다
- 빈 달은 막대·카테고리 대신 "이 달엔 기록이 없어요" 빈 상태 (요약 카드는 그대로 둔다)
- **개인 최고 기준**: 저장 성공 시 오늘 합계가 역대 하루 최고를, 이번 달 합계가 역대 월 최고를 넘기면 홈 저장 이펙트에 "하루 최고 기록! 🏆" / "이번 달 최고 기록! 🏆" 를 카드 아래 1.5초 표시. 그날·그달 최고선을 **처음 넘는 저장에서만 한 번** 뜨고, 이미 넘은 뒤 더 쌓는 저장에는 다시 뜨지 않는다. 둘 다면 월 우선. 비교 대상이 없는 첫 기록·첫 달과 동점은 최고로 치지 않고, 과거 날짜로 넣은 기록도 축하하지 않는다
- **수정은 이펙트 없음**: 기록 수정(`update`)은 새로 절약한 게 아니므로 카운트업·펄스·최고 기록 문구를 내지 않는다

### 4. 설정 탭 (`app/(tabs)/settings.tsx`)
- 섹션 목록 구조(회색 섹션 제목 + 행 묶음 카드). 첫 섹션 **목표**: "월 목표 금액" 행(값 또는 "없음") → 모달에서 금액 입력·프리셋 칩(10만/20만/30만/50만)·저장·목표 없애기 (M3.5)
- 카테고리 관리: 추가/이름·이모지 수정/순서 변경/삭제(기본 카테고리는 삭제 불가, 사용 중이면 경고)
- **백업**: 전체 데이터를 JSON 파일로 내보내기 → `expo-sharing` 으로 공유 시트(파일 앱, 카톡 등)
- **복원**: `expo-document-picker` 로 JSON 선택 → 병합 or 덮어쓰기 선택
  - 복원 데이터는 `addEntry` 와 같은 검증을 통과해야 함 (금액 1 이상 정수, 항목명 비어있지 않음) + `date` 가 `YYYY-MM-DD` 형식인지 `dayjs(date, DATE_FORMAT, true).isValid()` 로 검사. 하나라도 틀리면 해당 행 건너뛰고 건수 보고
- CSV 내보내기 (엑셀에서 열기용, UTF-8 BOM 포함)
- 앱 정보, 데이터 전체 삭제(2단계 확인)

### 5. 기록 수정 (`app/entry/[id].tsx`)
- 입력 시트와 같은 폼, 삭제 버튼 추가

## 비기능 요구사항
- 앱 켜면 1초 안에 홈 표시. 목록은 `FlatList`/`SectionList`, 페이지네이션(월 단위 로드)
- 오프라인 100%. 네트워크 요청 없음
- 다크모드 대응 (시스템 설정 따름)
- iPhone 세로 모드만

## 개발 단계 (이 순서로 진행)
1. **M1 뼈대**: 프로젝트 생성, 탭 3개, 테마, SQLite 초기화+마이그레이션, 기본 카테고리 시드
2. **M2 기록**: 입력 시트(모달), 저장 + 축하 이펙트, 홈 날짜별 목록(월/년 전환), 수정/삭제
3. **M3 월별**: 월 이동, 합계, 일별 막대, 카테고리별 합계, **개인 최고 갱신**(하루/한 달 역대 최고를 넘기면 저장 이펙트에 "최고 기록!" 한 줄)
3.5. **M3.5 월 목표**: `settings` 키-값 테이블(마이그레이션 v3), 설정 탭에서 월 목표 금액 입력(프리셋 칩 10만/20만/30만/50만, 없애기), 홈 카드 큰 숫자 아래 진행 바 + "목표 300,000원 · 62%". **달성 후에도 100%에서 멈추지 않고 "달성! +12,000원 초과"** 로 계속 표시. 달성 순간(이전 합계 < 목표 ≤ 새 합계, 목표당 월 1회 — 목표를 바꾸면 다시 축하 가능)에는 바가 끝까지 차오름 + 카드 배경 틴트 + 강한 햅틱 2연타 + "이번 달 목표 달성 🎉". 목표 없으면 "목표를 정하면 진행률이 보여요 →" 한 줄. 카테고리별 목표·월별 이력·미달 경고는 하지 않음
3.6. **M3.6 홈 활기** ("기록 없이 열어도 앱이 반응한다"): ① **오늘의 한 줄** — 카드 큰 숫자 위 한 줄, 상태별 우선순위: 목표 근접 > 오늘 기록 없음 → **절약 명언**(로컬 상수 30개 이상, 날짜 시드 로테이션) > 오늘 기록 있음 → 어제 대비("어제보다 +4,500원") / 환산("= 치킨 3마리 🍗", 커피→치킨→에어팟→항공권 10단계 사다리) 을 날짜 시드로 번갈아 > 그 외 명언. 정보형 톤, 환산에만 가벼운 유머, 이모지 문장당 1개, 채찍 문구 금지. 순수 함수 `src/features/dailyLine.ts`, 서버·AI 없음 ② **하루 첫 오픈 카운트업** — 그날 처음 열 때만 월 합계가 0→현재값 0.8초 (`AnimatedWon` 재사용, 마지막 오픈 날짜는 settings 테이블) ③ **이번 달 잔디** — 카드 아래 7열 달력, 기록한 날은 `primarySoft`→`primary` 농도, 오늘 칸 테두리, 일별 합계 쿼리 재사용 ④ **이모지 적립 줄** — 카드 안에 이번 달 기록 이모지가 시간순으로 쌓임(☕☕🍗🚕…), 저장하면 새 이모지가 톡 들어오는 짧은 애니메이션. 카드 배경색이 금액 따라 변하는 것은 하지 않음(DESIGN 규칙)
   - 구현 세부 (M3.6 에서 정함): 한 줄 우선순위는 목표 근접(80% 이상 100% 미만) > 오늘 기록 없음 → 명언 > 오늘 기록 있음 → 어제 대비 / 환산 번갈아(어제 기록이 없거나 어제보다 적으면 환산, 환산 못 하면 어제 대비) > 그 외 명언. 목표 달성 후 순위는 두지 않음(카드 목표 줄 "달성! +N원 초과" 와 겹침). 어제보다 적은 날의 "-N원" 문구도 두지 않음. 변형은 `YYYY-MM-DD` 해시 시드. "첫 기록 대기" 문구는 두지 않음
   - 환산 사다리(가격 오름차순, 합계 이하인 가장 비싼 칸 · 개수 소수 버림): 커피 4,500 ☕ · 영화 15,000 🎬 · 치킨 20,000 🍗 · 배달 25,000 🛵 · 운동화 90,000 👟 · 에어팟 250,000 🎧 · 호캉스 300,000 🏨 · 아이패드 700,000 📱 · 항공권 900,000 ✈️ · 노트북 1,500,000 💻. 4,500원 미만이면 명언
   - 명언 36개(`src/features/quotes.ts`), 날짜 순번으로 하루 하나. 출처가 흐린 말은 출처 없이 격언으로
   - 잔디 농도: 그날 합계 / 그달 최댓값이 (0, 25%] 1단계 · (25, 50%] 2 · (50, 75%] 3 · (75, 100%] 4 (`grass1~4` 토큰), 기록 없는 날 `divider`, 미래 `grassFuture`, 오늘 `primary` 2px 테두리
   - 첫 오픈: settings `last_open_date` 가 오늘과 다르거나 없으면 홈 포커스 때 0 → 월 합계 0.8초. 같은 날 재오픈(앱 재시작 포함)은 카운트업 없이 즉시 표시
   - 이모지 줄: 3줄을 넘으면 오래된 것을 접어 맨 앞 "+N", 방금 저장한 것이 오른쪽 끝에 남는다
4. **M4 편의**: 빠른 입력 칩, **연속 기록일**(카드 구석 "🔥 5일째", 끊기면 0으로만 표시하고 경고 없음), **누적 이정표**(카드 구석 "누적 432,000원", 10만·50만·100만·500만·1,000만 돌파 저장 시 RecordBanner 로 1회 축하, settings 에 달성 기록), **지난달 회고 카드**(매달 1~3일에만 홈 맨 위 "9월엔 23번 참아 184,000원 · 최다 ☕", 닫으면 settings 에 기록), 다크모드 마무리, 입력 시트를 바텀시트로 교체할지 재결정
5. **M5 백업**: JSON 내보내기/복원, CSV, 카테고리 관리
각 단계 끝날 때 `/check` 통과 + 아이폰 Expo Go에서 실제 확인.
