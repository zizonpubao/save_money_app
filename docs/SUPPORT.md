# SaveLog 지원

SaveLog는 "오늘 참은 소비"를 기록하는 절약 앱입니다.
사용 중 문제가 있거나 제안이 있으면 아래 방법으로 알려 주세요.

## 자주 묻는 질문

### 기록은 어디에 저장되나요?
아이폰 안에만 저장됩니다. 서버나 클라우드로 보내지 않습니다.

### 휴대폰을 바꾸면 기록을 옮길 수 있나요?
설정 → 백업 → "JSON 으로 내보내기"로 파일을 만든 뒤, 새 휴대폰의 SaveLog에서 설정 → 백업 → "JSON 에서 복원"으로 불러오면 됩니다.

### 효과음이 안 들려요.
아이폰이 무음 모드면(무음 스위치, 액션 버튼, 제어 센터) 효과음 대신 진동만 납니다. 설정 → 효과에서 효과음이 켜져 있는지도 확인해 주세요.

### 기록을 모두 지우고 싶어요.
설정 → 앱 정보 → 데이터 전체 삭제를 누르면 됩니다. 지운 기록은 되돌릴 수 없으니 먼저 백업을 내보내 두세요.
