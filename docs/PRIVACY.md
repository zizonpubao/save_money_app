# SaveLog 개인정보 처리방침

시행일: 2026년 10월 19일

SaveLog(이하 "앱")는 사용자의 개인정보를 수집하지 않습니다.
이 문서는 앱이 어떤 정보를 어디에 두는지 설명합니다.

## 1. 수집하는 개인정보

앱은 개인정보를 수집하지 않습니다.

- 회원가입과 로그인이 없습니다.
- 앱은 서버를 쓰지 않고, 입력한 내용을 인터넷으로 보내지 않습니다.
- 광고, 분석, 추적 도구를 넣지 않았습니다.
- 위치, 연락처, 사진, 카메라, 마이크에 접근하지 않습니다.

## 2. 기기에 저장되는 정보

사용자가 입력한 내용은 사용자의 아이폰 안에만 저장됩니다.

| 저장되는 정보 | 예시 |
|---|---|
| 절약 기록 | 금액, 항목 이름, 카테고리, 날짜, 메모 |
| 앱 설정 | 월 목표 금액, 테마, 효과음·햅틱 켜짐 여부, 빠른 금액 버튼 |

개발자를 포함한 누구도 이 정보에 접근할 수 없습니다.

## 3. 백업 파일

설정의 백업 기능을 쓰면 기록을 JSON 또는 CSV 파일로 내보낼 수 있습니다.

- 파일은 사용자가 직접 내보내기를 누를 때만 만들어집니다.
- 저장하거나 보낼 곳(파일 앱, 메시지 등)은 사용자가 고릅니다.
- 내보낸 파일의 관리 책임은 그 파일을 저장하거나 보낸 사용자에게 있습니다.

## 4. 기기 권한

앱 정보에는 마이크 사용 설명 문구가 들어 있습니다.
효과음을 재생하는 오디오 모듈에 녹음 기능이 함께 포함돼 있어 표시되는 항목입니다.
앱은 마이크를 쓰지 않으며 마이크 권한을 요청하지 않습니다.

## 5. 정보 삭제

- 설정 → 앱 정보 → 데이터 전체 삭제로 모든 기록을 지울 수 있습니다.
- 앱을 삭제하면 기기에 저장된 모든 기록과 설정이 함께 지워집니다.

## 6. 아동의 개인정보

앱은 누구의 개인정보도 수집하지 않으므로, 만 14세 미만 아동의 개인정보도 수집하지 않습니다.
